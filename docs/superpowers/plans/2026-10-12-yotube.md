# Yotube Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Yotube, a self-hosted, single-container web app that turns YouTube Music searches and playlists into Yoto MYO playlists, kept in sync on demand and nightly.

**Architecture:** One Python process (FastAPI) serves a REST API, an SSE progress stream and a compiled Svelte UI. A sync engine mirrors a source (YouTube Music playlist or hand-picked tracks) into a Yoto playlist: it downloads missing audio with yt-dlp, uploads it to Yoto (Yoto transcodes), picks a 16×16 icon per track and rewrites the Yoto content in one call. State lives in SQLite under `/data`; APScheduler triggers the nightly sync.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy 2 + Alembic, httpx, ytmusicapi, yt-dlp (+ Deno for YouTube JS challenges), APScheduler 3, anthropic SDK, sse-starlette; Svelte 5 + Vite 6 + TypeScript, Vitest; Docker multi-stage build; GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-12-yotube-design.md`

## Global Constraints

- Python `>=3.12` in `pyproject.toml`; Docker runtime and CI use Python 3.13. Node 22 for the UI build.
- All code, comments, identifiers, log messages, commit messages and the README are in English. Every UI string lives in `frontend/src/lib/locales/{en,fr,ru}.json`, and the three files have identical key sets.
- Commit messages: Conventional Commits style, **no `Co-Authored-By` or "Generated with" trailers**. Commit with the repo-local git identity already configured; never touch global git config.
- One Docker image, non-root user, data volume `/data`, HTTP port `8080`. No ffmpeg in the image.
- Configuration via env only: `YOTO_CLIENT_ID` (required), `PUBLIC_URL` (default `http://localhost:8080`), `ANTHROPIC_API_KEY` (optional), `ANTHROPIC_MODEL` (default `claude-haiku-5-5`), `SYNC_CRON` (default `0 3 * * *`), `TZ` (default `Europe/Paris`), `PORT` (default `8080`), `YTDLP_AUTO_UPDATE` (default `true`), `LOG_LEVEL` (default `INFO`).
- Yoto OAuth: Authorization Code + PKCE on `https://login.yotoplay.com`, audience `https://api.yotoplay.com`, scopes `user:content:manage offline_access`, redirect URI `${PUBLIC_URL}/auth/callback`. Refresh tokens are single-use: persist the new one on every refresh.
- Yoto limit: at most 100 chapters per playlist (`MAX_CHAPTERS = 100`).
- One sync at a time app-wide; at most 2 tracks transferred concurrently inside a sync.
- Mirror exact: Yoto content = source order (or shuffled when `shuffle` is on); removed source tracks disappear; a track that is unavailable on YouTube but already uploaded is kept and flagged.
- No Yoto logo or brand assets; the look is "Yoto-inspired" (bright colours, rounded cards, pixel icons, Nunito).
- No in-app authentication; README warns against exposing the app to the internet.

## Review Focus

1. **YouTube Music link variants** — share links with `&si=`, `watch?v=…&list=…`, `m.youtube.com`, `youtu.be`, `browse/VL…` ids and bare ids must all resolve to the playlist id; anything else must fail with a friendly "not a playlist link" error, never a 500. Pinned in Task 6 (`test_urls.py`).
2. **Same song twice in one playlist** — both positions appear as chapters, the audio is downloaded and uploaded once. Pinned in Task 8 (`test_duplicate_video_uploaded_once_but_kept_twice`).
3. **Playlist deleted in the Yoto app** — the next sync must recreate the Yoto content and store the new card id instead of failing forever. Pinned in Task 4 (`test_save_content_raises_content_not_found_for_deleted_card`) and Task 8 (`test_deleted_yoto_card_is_recreated`).
4. **Source playlist emptied or made private** — the sync fails with a clear error and must not overwrite the existing Yoto playlist with nothing. Pinned in Task 8 (`test_empty_source_fails_without_touching_yoto`, `test_private_source_playlist_fails_cleanly`).
5. **Non-Latin and accented titles** — Russian (`Кошка`) and French (`Éléphant`) titles must still find a matching icon. Pinned in Task 7 (`test_keywords_translate_french_and_russian`, `test_picker_matches_cyrillic_title`).

```python
from typing import Any

from sqlalchemy import Engine, create_engine, event
from sqlalchemy.orm import Session, sessionmaker


def make_engine(database_url: str) -> Engine:
    engine = create_engine(database_url, connect_args={"check_same_thread": False})

    @event.listens_for(engine, "connect")
    def _sqlite_pragmas(dbapi_connection: Any, _record: Any) -> None:
        cursor = dbapi_connection.cursor()
        cursor.execute("PRAGMA foreign_keys=ON")
        cursor.execute("PRAGMA journal_mode=WAL")
        cursor.close()

    return engine


def make_session_factory(engine: Engine) -> sessionmaker[Session]:
    return sessionmaker(engine, expire_on_commit=False)
```

```python
from sqlalchemy.orm import Session, sessionmaker

from app.db.models import AppSetting


class DbSettingsStore:
    """Small key/value store for app-level settings (UI language, cached icon ids…)."""

    def __init__(self, sessions: sessionmaker[Session]) -> None:
        self._sessions = sessions

    def get(self, key: str) -> str | None:
        with self._sessions() as session:
            setting = session.get(AppSetting, key)
            return setting.value if setting else None

    def set(self, key: str, value: str) -> None:
        with self._sessions.begin() as session:
            session.merge(AppSetting(key=key, value=value))
```

```python
import asyncio
import base64
import hashlib
import secrets
from collections.abc import Callable
from dataclasses import dataclass
from datetime import datetime, timedelta
from typing import Any, Protocol
from urllib.parse import urlencode

import httpx

from app.timeutil import utcnow
from app.yoto.errors import AuthRequired, LoginError

REFRESH_MARGIN = timedelta(seconds=60)


@dataclass(frozen=True)
class TokenSet:
    access_token: str
    refresh_token: str
    expires_at: datetime


class TokenStore(Protocol):
    def load(self) -> TokenSet | None: ...
    def save(self, tokens: TokenSet) -> None: ...
    def clear(self) -> None: ...


def make_pkce_pair() -> tuple[str, str]:
    """Return a (code_verifier, S256 code_challenge) pair."""
    verifier = secrets.token_urlsafe(64)
    digest = hashlib.sha256(verifier.encode()).digest()
    challenge = base64.urlsafe_b64encode(digest).rstrip(b"=").decode()
    return verifier, challenge


class YotoAuth:
    """OAuth 2 Authorization Code + PKCE against Yoto, with transparent token refresh."""

    SCOPES = "user:content:manage offline_access"
    AUDIENCE = "https://api.yotoplay.com"

    def __init__(
        self,
        client_id: str,
        auth_base_url: str,
        redirect_uri: str,
        store: TokenStore,
        http: httpx.AsyncClient,
        clock: Callable[[], datetime] = utcnow,
    ) -> None:
        self._client_id = client_id
        self._base = auth_base_url.rstrip("/")
        self._redirect_uri = redirect_uri
        self._store = store
        self._http = http
        self._clock = clock
        self._pending: dict[str, str] = {}  # state -> code_verifier
        self._lock = asyncio.Lock()

    def authorization_url(self) -> str:
        verifier, challenge = make_pkce_pair()
        state = secrets.token_urlsafe(16)
        self._pending[state] = verifier
        params = {
            "audience": self.AUDIENCE,
            "scope": self.SCOPES,
            "response_type": "code",
            "client_id": self._client_id,
            "code_challenge": challenge,
            "code_challenge_method": "S256",
            "redirect_uri": self._redirect_uri,
            "state": state,
        }
        return f"{self._base}/authorize?{urlencode(params)}"

    async def handle_callback(self, code: str, state: str) -> None:
        verifier = self._pending.pop(state, None)
        if verifier is None:
            raise LoginError("Unknown or expired login attempt, please try again")
        response = await self._http.post(
            f"{self._base}/oauth/token",
            data={
                "grant_type": "authorization_code",
                "client_id": self._client_id,
                "code_verifier": verifier,
                "code": code,
                "redirect_uri": self._redirect_uri,
            },
        )
        if response.is_error:
            raise LoginError(f"Yoto refused the login (HTTP {response.status_code})")
        self._store_tokens(response.json(), previous_refresh_token=None)

    def is_connected(self) -> bool:
        return self._store.load() is not None

    def logout(self) -> None:
        self._store.clear()

    async def access_token(self) -> str:
        async with self._lock:
            tokens = self._store.load()
            if tokens is None:
                raise AuthRequired("Not connected to Yoto")
            if tokens.expires_at - REFRESH_MARGIN > self._clock():
                return tokens.access_token
            response = await self._http.post(
                f"{self._base}/oauth/token",
                data={
                    "grant_type": "refresh_token",
                    "client_id": self._client_id,
                    "refresh_token": tokens.refresh_token,
                },
            )
            if response.status_code in (400, 401, 403):
                self._store.clear()
                raise AuthRequired("The Yoto session has expired")
            response.raise_for_status()
            return self._store_tokens(response.json(), tokens.refresh_token).access_token

    def _store_tokens(
        self, payload: dict[str, Any], previous_refresh_token: str | None
    ) -> TokenSet:
        refresh_token = payload.get("refresh_token") or previous_refresh_token
        if not refresh_token:
            raise LoginError("Yoto did not return a refresh token (is offline_access enabled?)")
        tokens = TokenSet(
            access_token=str(payload["access_token"]),
            refresh_token=str(refresh_token),
            expires_at=self._clock() + timedelta(seconds=int(payload.get("expires_in", 3600))),
        )
        self._store.save(tokens)
        return tokens
```

```python
from sqlalchemy.orm import Session, sessionmaker

from app.db.models import OAuthToken
from app.yoto.auth import TokenSet

_TOKEN_ROW_ID = 1


class DbTokenStore:
    """Persists the single Yoto token set in SQLite."""

    def __init__(self, sessions: sessionmaker[Session]) -> None:
        self._sessions = sessions

    def load(self) -> TokenSet | None:
        with self._sessions() as session:
            row = session.get(OAuthToken, _TOKEN_ROW_ID)
            if row is None:
                return None
            return TokenSet(row.access_token, row.refresh_token, row.expires_at)

    def save(self, tokens: TokenSet) -> None:
        with self._sessions.begin() as session:
            session.merge(
                OAuthToken(
                    id=_TOKEN_ROW_ID,
                    access_token=tokens.access_token,
                    refresh_token=tokens.refresh_token,
                    expires_at=tokens.expires_at,
                )
            )

    def clear(self) -> None:
        with self._sessions.begin() as session:
            row = session.get(OAuthToken, _TOKEN_ROW_ID)
            if row is not None:
                session.delete(row)
```

```python
import asyncio
import logging
from collections.abc import Awaitable, Callable, Sequence
from pathlib import Path
from typing import Any, Protocol

import httpx

from app.yoto.errors import AuthRequired, ContentNotFound, YotoError
from app.yoto.models import Icon, UploadedAudio

log = logging.getLogger(__name__)

RETRYABLE_STATUS = frozenset({429, 500, 502, 503, 504})


class TokenProvider(Protocol):
    async def access_token(self) -> str: ...


class YotoClient:
    """Thin async client for the Yoto API endpoints Yotube needs."""

    def __init__(
        self,
        tokens: TokenProvider,
        http: httpx.AsyncClient,
        base_url: str = "https://api.yotoplay.com",
        *,
        poll_interval: float = 1.0,
        poll_attempts: int = 180,
        retry_delays: Sequence[float] = (1.0, 2.0, 4.0),
        sleep: Callable[[float], Awaitable[None]] = asyncio.sleep,
    ) -> None:
        self._tokens = tokens
        self._http = http
        self._base = base_url.rstrip("/")
        self._poll_interval = poll_interval
        self._poll_attempts = poll_attempts
        self._retry_delays = tuple(retry_delays)
        self._sleep = sleep

    async def upload_audio(self, path: Path, mime: str) -> UploadedAudio:
        data = self._json(
            await self._request("GET", "/media/transcode/audio/uploadUrl"), "Requesting an upload URL"
        )
        upload = data["upload"]
        upload_url: str | None = upload.get("uploadUrl")
        upload_id = str(upload["uploadId"])

        if upload_url:  # Yoto returns no URL when it already has this exact file.
            content = await asyncio.to_thread(path.read_bytes)
            response = await self._http.put(upload_url, content=content, headers={"Content-Type": mime})
            if response.is_error:
                raise YotoError(f"Uploading audio failed (HTTP {response.status_code})")

        for _ in range(self._poll_attempts):
            data = self._json(
                await self._request(
                    "GET", f"/media/upload/{upload_id}/transcoded", params={"loudnorm": "false"}
                ),
                "Checking transcoding status",
            )
            transcode = data.get("transcode") or {}
            sha256 = transcode.get("transcodedSha256")
            if sha256:
                info = transcode.get("transcodedInfo") or {}
                return UploadedAudio(
                    sha256=str(sha256),
                    duration=round(float(info.get("duration") or 0)),
                    file_size=int(info.get("fileSize") or 0),
                    channels=str(info.get("channels") or "stereo"),
                    format=str(info.get("format") or "aac"),
                )
            await self._sleep(self._poll_interval)
        raise YotoError("Yoto did not finish transcoding in time")

    async def upload_cover_from_url(self, image_url: str) -> str:
        image = await self._http.get(image_url)
        if image.is_error:
            raise YotoError(f"Downloading the cover image failed (HTTP {image.status_code})")
        response = await self._request(
            "POST",
            "/media/coverImage/user/me/upload",
            params={"autoconvert": "true", "coverType": "default"},
            content=image.content,
            headers={"Content-Type": image.headers.get("Content-Type", "image/jpeg")},
        )
        return str(self._json(response, "Uploading the cover")["coverImage"]["mediaUrl"])

    async def upload_icon(self, png: bytes, filename: str) -> Icon:
        response = await self._request(
            "POST",
            "/media/displayIcons/user/me/upload",
            params={"autoConvert": "true", "filename": filename},
            files={"file": (filename, png, "image/png")},
        )
        icon = self._json(response, "Uploading an icon")["displayIcon"]
        return Icon(media_id=str(icon["mediaId"]), title=filename, url=str(icon.get("url", "")))

    async def list_public_icons(self) -> list[Icon]:
        response = await self._request("GET", "/media/displayIcons/user/yoto")
        return [
            Icon(
                media_id=str(item["mediaId"]),
                title=str(item.get("title") or ""),
                url=str(item.get("url") or ""),
                tags=tuple(str(tag) for tag in item.get("publicTags") or ()),
            )
            for item in self._json(response, "Listing public icons").get("displayIcons", [])
        ]

    async def save_content(self, body: dict[str, Any], card_id: str | None) -> str:
        payload = {**body, "cardId": card_id} if card_id else body
        response = await self._request("POST", "/content", json=payload)
        if (
            response.is_error
            and card_id is not None
            and response.status_code in (400, 404)
            and not await self._content_exists(card_id)
        ):
            raise ContentNotFound(card_id)
        return str(self._json(response, "Saving the playlist")["card"]["cardId"])

    async def delete_content(self, card_id: str) -> None:
        response = await self._request("DELETE", f"/content/{card_id}")
        if response.status_code != 404:
            self._json(response, "Deleting the playlist")

    async def _content_exists(self, card_id: str) -> bool:
        response = await self._request("GET", f"/content/{card_id}")
        if response.status_code == 404:
            return False
        if response.is_success:
            card = response.json().get("card") or {}
            return not card.get("deleted", False)
        return True

    async def _request(self, method: str, path: str, **kwargs: Any) -> httpx.Response:
        extra_headers: dict[str, str] = kwargs.pop("headers", {})
        delays: tuple[float | None, ...] = (*self._retry_delays, None)
        for delay in delays:
            headers = {
                "Authorization": f"Bearer {await self._tokens.access_token()}",
                "Accept": "application/json",
                **extra_headers,
            }
            try:
                response = await self._http.request(
                    method, f"{self._base}{path}", headers=headers, **kwargs
                )
            except httpx.TransportError as exc:
                if delay is None:
                    raise YotoError(f"Network error while calling Yoto: {exc}") from exc
                log.warning("Yoto %s %s failed (%s), retrying", method, path, exc)
                await self._sleep(delay)
                continue
            if response.status_code == 401:
                raise AuthRequired("Yoto rejected the access token")
            if response.status_code in RETRYABLE_STATUS and delay is not None:
                log.warning("Yoto %s %s returned %s, retrying", method, path, response.status_code)
                await self._sleep(delay)
                continue
            return response
        raise AssertionError("unreachable")

    @staticmethod
    def _json(response: httpx.Response, action: str) -> dict[str, Any]:
        if response.is_error:
            raise YotoError(f"{action} failed (HTTP {response.status_code}): {response.text[:300]}")
        data: dict[str, Any] = response.json()
        return data
```

```python
from collections.abc import Sequence
from dataclasses import dataclass
from typing import Any

MAX_CHAPTERS = 100


@dataclass(frozen=True)
class ContentTrack:
    title: str
    sha256: str
    duration: int
    file_size: int
    channels: str
    format: str
    icon_media_id: str | None = None


def build_content(
    title: str,
    tracks: Sequence[ContentTrack],
    *,
    shuffle: bool,
    cover_url: str | None = None,
) -> dict[str, Any]:
    """Build the JSON body of `POST /content`: one chapter per track, in the given order."""
    selected = list(tracks)[:MAX_CHAPTERS]
    content: dict[str, Any] = {
        "chapters": [_chapter(index, t) for index, t in enumerate(selected, start=1)],
        "playbackType": "linear",
    }
    if shuffle and len(selected) > 1:
        # Native player shuffle: reshuffles every time the card is played.
        last = len(selected) - 1
        content["config"] = {"shuffle": [{"start": 0, "end": last, "limit": len(selected)}]}

    total_size = sum(t.file_size for t in selected)
    metadata: dict[str, Any] = {
        "media": {
            "duration": sum(t.duration for t in selected),
            "fileSize": total_size,
            "readableFileSize": round(total_size / 1024 / 1024, 1),
        }
    }
    if cover_url:
        metadata["cover"] = {"imageL": cover_url}
    return {"title": title, "content": content, "metadata": metadata}


def _chapter(index: int, track: ContentTrack) -> dict[str, Any]:
    label = str(index)
    audio: dict[str, Any] = {
        "key": "01",
        "title": track.title,
        "trackUrl": f"yoto:#{track.sha256}",
        "duration": track.duration,
        "fileSize": track.file_size,
        "channels": int(track.channels) if track.channels.isdigit() else track.channels,
        "format": track.format,
        "type": "audio",
        "overlayLabel": label,
    }
    chapter: dict[str, Any] = {
        "key": f"{index:02d}",
        "title": track.title,
        "overlayLabel": label,
        "tracks": [audio],
    }
    if track.icon_media_id:
        display = {"icon16x16": f"yoto:#{track.icon_media_id}"}
        chapter["display"] = display
        audio["display"] = display
    return chapter
```

```python
import re
from urllib.parse import parse_qs, urlparse

from app.youtube.models import InvalidPlaylistUrl

_ID_RE = re.compile(r"^[A-Za-z0-9_-]{10,80}$")
_HOSTS = frozenset(
    {"music.youtube.com", "www.youtube.com", "youtube.com", "m.youtube.com", "youtu.be"}
)


def parse_playlist_id(value: str) -> str:
    """Extract a playlist id from a YouTube / YouTube Music link or a bare id."""
    text = value.strip()
    if not text:
        raise InvalidPlaylistUrl("The playlist link is empty")

    if "/" not in text and "?" not in text:
        candidate = text
    else:
        url = urlparse(text if "://" in text else f"https://{text}")
        if url.hostname not in _HOSTS:
            raise InvalidPlaylistUrl("This is not a YouTube Music link")
        query = parse_qs(url.query)
        if "list" in query:
            candidate = query["list"][0]
        elif url.path.startswith("/browse/"):
            candidate = url.path.removeprefix("/browse/")
        else:
            raise InvalidPlaylistUrl("This link does not point to a playlist")

    if candidate.startswith("VL"):
        candidate = candidate[2:]
    if not _ID_RE.match(candidate):
        raise InvalidPlaylistUrl("This link does not contain a valid playlist id")
    return candidate
```

```python
import asyncio
from collections.abc import Callable
from pathlib import Path
from typing import Any

import yt_dlp
from ytmusicapi import YTMusic

from app.youtube.models import (
    DownloadedAudio,
    DownloadFailed,
    PlaylistInfo,
    PlaylistNotFound,
    TrackInfo,
    TrackUnavailable,
)
from app.youtube.urls import parse_playlist_id

MIME_BY_EXTENSION = {
    "m4a": "audio/mp4",
    "mp4": "audio/mp4",
    "webm": "audio/webm",
    "opus": "audio/ogg",
    "ogg": "audio/ogg",
    "mp3": "audio/mpeg",
}

# yt-dlp error fragments that mean "this video will never download".
_UNAVAILABLE_MARKERS = (
    "video unavailable",
    "private video",
    "has been removed",
    "not available",
    "blocked",
    "copyright",
    "terminated",
    "confirm your age",
)


class YouTubeMusicSource:
    """Reads YouTube Music (search, playlists) and downloads audio with yt-dlp."""

    def __init__(
        self,
        tmp_dir: Path,
        ytmusic: Any | None = None,
        ydl_factory: Callable[[dict[str, Any]], Any] | None = None,
    ) -> None:
        self._tmp_dir = tmp_dir
        self._ytmusic = ytmusic
        self._ydl_factory = ydl_factory or yt_dlp.YoutubeDL

    def _client(self) -> Any:
        if self._ytmusic is None:
            self._ytmusic = YTMusic()
        return self._ytmusic

    async def search(self, query: str, limit: int = 20) -> list[TrackInfo]:
        results = await asyncio.to_thread(self._client().search, query, filter="songs", limit=limit)
        tracks = [track for raw in results if (track := _track_from(raw))]
        return tracks[:limit]

    async def get_playlist(self, url_or_id: str) -> PlaylistInfo:
        playlist_id = parse_playlist_id(url_or_id)
        try:
            raw = await asyncio.to_thread(self._client().get_playlist, playlist_id, limit=None)
        except Exception as exc:  # ytmusicapi raises bare Exceptions for HTTP errors
            raise PlaylistNotFound(f"Could not read playlist {playlist_id}: {exc}") from exc
        tracks = [track for item in raw.get("tracks") or [] if (track := _track_from(item))]
        return PlaylistInfo(
            playlist_id=playlist_id,
            title=raw.get("title") or playlist_id,
            thumbnail_url=_best_thumbnail(raw.get("thumbnails")),
            tracks=tracks,
        )

    async def download_audio(self, video_id: str) -> DownloadedAudio:
        return await asyncio.to_thread(self._download, video_id)

    def _download(self, video_id: str) -> DownloadedAudio:
        self._tmp_dir.mkdir(parents=True, exist_ok=True)
        options = {
            "format": "bestaudio[ext=m4a]/bestaudio",
            "outtmpl": str(self._tmp_dir / f"{video_id}.%(ext)s"),
            "noplaylist": True,
            "quiet": True,
            "no_warnings": True,
            "noprogress": True,
            "overwrites": True,
        }
        try:
            with self._ydl_factory(options) as ydl:
                info = ydl.extract_info(f"https://music.youtube.com/watch?v={video_id}", download=True)
        except yt_dlp.utils.DownloadError as exc:
            message = str(exc)
            if any(marker in message.lower() for marker in _UNAVAILABLE_MARKERS):
                raise TrackUnavailable(message) from exc
            raise DownloadFailed(message) from exc
        path = Path(info["requested_downloads"][0]["filepath"])
        mime = MIME_BY_EXTENSION.get(path.suffix.lstrip(".").lower(), "application/octet-stream")
        return DownloadedAudio(path=path, mime=mime)


def _track_from(raw: dict[str, Any]) -> TrackInfo | None:
    video_id = raw.get("videoId")
    if not video_id:
        return None
    artists = ", ".join(a["name"] for a in raw.get("artists") or [] if a.get("name"))
    return TrackInfo(
        video_id=str(video_id),
        title=raw.get("title") or str(video_id),
        artist=artists,
        duration=raw.get("duration_seconds"),
        thumbnail_url=_best_thumbnail(raw.get("thumbnails")),
        available=raw.get("isAvailable", True) is not False,
    )


def _best_thumbnail(thumbnails: list[dict[str, Any]] | None) -> str | None:
    if not thumbnails:
        return None
    return max(thumbnails, key=lambda t: t.get("width", 0)).get("url")
```

```python
import re
import unicodedata
from collections.abc import Sequence

from app.icons.synonyms import RAW_TRANSLATIONS
from app.yoto.models import Icon

_WORD_RE = re.compile(r"\w+", re.UNICODE)

STOPWORDS = frozenset(
    {
        # English
        "the", "and", "for", "you", "with", "song", "songs", "kids", "children", "version",
        "remix", "remastered", "official", "video", "audio", "lyrics", "feat", "live", "edit",
        # French
        "les", "des", "une", "est", "dans", "pour", "sur", "avec", "aux", "qui", "mon", "ton",
        "son", "mes", "tes", "ses", "comptine", "comptines",
        # Russian
        "и", "в", "на", "не", "что", "как", "мой", "моя", "это", "для", "песенка",
    }
)


def normalize(text: str) -> str:
    """Casefold and strip combining accents (é → e, ё → е)."""
    decomposed = unicodedata.normalize("NFKD", text.casefold())
    return "".join(c for c in decomposed if not unicodedata.combining(c))


TRANSLATIONS = {normalize(word): english for word, english in RAW_TRANSLATIONS.items()}


def keywords(text: str) -> list[str]:
    """Meaningful words of a title, translated to English when known, without duplicates."""
    result: list[str] = []
    for raw in _WORD_RE.findall(text):
        word = normalize(raw)
        if len(word) < 3 or word.isdigit() or word in STOPWORDS:
            continue
        word = TRANSLATIONS.get(word, word)
        if word not in result:
            result.append(word)
    return result


def _score(words: Sequence[str], icon: Icon) -> int:
    title_words = {normalize(w) for w in _WORD_RE.findall(icon.title)}
    tags = {normalize(t) for t in icon.tags}
    score = 0
    for word in words:
        if word in title_words:
            score += 3
        elif word in tags:
            score += 2
        elif any(_prefix_match(word, candidate) for candidate in title_words | tags):
            score += 1
    return score


def _prefix_match(word: str, candidate: str) -> bool:
    if len(candidate) >= 3 and word.startswith(candidate):  # "trains" ~ "train"
        return True
    return len(word) >= 4 and candidate.startswith(word)  # "drag" ~ "dragon"


def rank(words: Sequence[str], icons: Sequence[Icon]) -> list[Icon]:
    scored = [(score, index, icon) for index, icon in enumerate(icons) if (score := _score(words, icon)) > 0]
    scored.sort(key=lambda item: (-item[0], item[1]))
    return [icon for _, _, icon in scored]


def best_match(words: Sequence[str], icons: Sequence[Icon]) -> Icon | None:
    ranked = rank(words, icons)
    return ranked[0] if ranked else None
```

```python
import asyncio
import logging
from collections.abc import Callable
from datetime import datetime, timedelta
from typing import Protocol

from app.icons.matcher import keywords, normalize, rank
from app.timeutil import utcnow
from app.yoto.models import Icon

log = logging.getLogger(__name__)


class IconSource(Protocol):
    async def list_public_icons(self) -> list[Icon]: ...


class IconCatalog:
    """Yoto's public icon list, cached in memory and refreshed once a day."""

    def __init__(
        self,
        source: IconSource,
        ttl: timedelta = timedelta(hours=24),
        clock: Callable[[], datetime] = utcnow,
    ) -> None:
        self._source = source
        self._ttl = ttl
        self._clock = clock
        self._icons: list[Icon] = []
        self._loaded_at: datetime | None = None
        self._lock = asyncio.Lock()

    async def icons(self) -> list[Icon]:
        async with self._lock:
            fresh = self._loaded_at is not None and self._clock() - self._loaded_at < self._ttl
            if not fresh:
                try:
                    self._icons = await self._source.list_public_icons()
                    self._loaded_at = self._clock()
                except Exception:
                    if not self._icons:
                        raise
                    log.warning("Refreshing Yoto icons failed; keeping cached list", exc_info=True)
            return self._icons

    async def search(self, query: str, limit: int = 60) -> list[Icon]:
        icons = await self.icons()
        if not query.strip():
            return icons[:limit]
        words = keywords(query) or [normalize(query.strip())]
        return rank(words, icons)[:limit]
```

```python
# Beamed eighth notes, '#' = filled pixel.
NOTE_PATTERN: tuple[str, ...] = (
    "................",
    "......########..",
    "......########..",
    "......#......#..",
    "......#......#..",
    "......#......#..",
    "......#......#..",
    "......#......#..",
    "......#......#..",
    "...####...####..",
    "..#####..#####..",
    "..#####..#####..",
    "...###....###...",
    "................",
    "................",
    "................",
)


def render_note_png(hex_color: str) -> bytes:
    """Render the music-note icon as a 16x16 RGBA PNG in the given colour."""
    red, green, blue = (int(hex_color[i : i + 2], 16) for i in (1, 3, 5))
    filled = bytes((red, green, blue, 255))
    empty = bytes(4)
    raw = b"".join(
        b"\x00" + b"".join(filled if pixel == "#" else empty for pixel in row)
        for row in NOTE_PATTERN
    )

    def chunk(tag: bytes, data: bytes) -> bytes:
        crc = zlib.crc32(tag + data) & 0xFFFFFFFF
        return struct.pack(">I", len(data)) + tag + data + struct.pack(">I", crc)

    header = struct.pack(">IIBBBBB", 16, 16, 8, 6, 0, 0, 0)
    return (
        b"\x89PNG\r\n\x1a\n"
        + chunk(b"IHDR", header)
        + chunk(b"IDAT", zlib.compress(raw))
        + chunk(b"IEND", b"")
    )
```

```python
import logging
from dataclasses import dataclass
from typing import Protocol

from app.icons.catalog import IconCatalog
from app.icons.default_icon import PLAYLIST_COLORS, render_note_png
from app.icons.matcher import best_match, keywords, normalize
from app.yoto.models import Icon

log = logging.getLogger(__name__)


@dataclass(frozen=True)
class IconChoice:
    media_id: str
    url: str


class KeywordSuggester(Protocol):
    async def suggest(self, title: str, artist: str) -> list[str]: ...


class IconUploader(Protocol):
    async def upload_icon(self, png: bytes, filename: str) -> Icon: ...


class SettingsStore(Protocol):
    def get(self, key: str) -> str | None: ...
    def set(self, key: str, value: str) -> None: ...


class IconPicker:
    """Chooses a track icon: Claude keywords → title keywords → coloured music note."""

    def __init__(
        self,
        catalog: IconCatalog,
        uploader: IconUploader,
        settings: SettingsStore,
        suggester: KeywordSuggester | None = None,
    ) -> None:
        self._catalog = catalog
        self._uploader = uploader
        self._settings = settings
        self._suggester = suggester

    async def pick(self, title: str, artist: str, color: str) -> IconChoice | None:
        try:
            icons = await self._catalog.icons()
        except Exception:
            log.warning("Yoto icon catalog unavailable", exc_info=True)
            icons = []

        if icons and self._suggester is not None:
            try:
                words = [normalize(w) for w in await self._suggester.suggest(title, artist)]
                if match := best_match(words, icons):
                    return IconChoice(match.media_id, match.url)
            except Exception:
                log.warning("Claude icon suggestion failed for %r", title, exc_info=True)

        if icons and (match := best_match(keywords(title), icons)):
            return IconChoice(match.media_id, match.url)

        return await self.default_icon(color)

    async def default_icon(self, color: str) -> IconChoice | None:
        color = color if color in PLAYLIST_COLORS else "orange"
        key = f"default_icon:{color}"
        if stored := self._settings.get(key):
            media_id, url = stored.split("|", 1)
            return IconChoice(media_id, url)
        try:
            icon = await self._uploader.upload_icon(
                render_note_png(PLAYLIST_COLORS[color]), f"yotube-note-{color}.png"
            )
        except Exception:
            log.warning("Uploading the default icon failed", exc_info=True)
            return None
        self._settings.set(key, f"{icon.media_id}|{icon.url}")
        return IconChoice(icon.media_id, icon.url)
```

```python
def mirror_tracks(playlist: Playlist, source: Sequence[TrackInfo]) -> None:
    """Make `playlist.tracks` match `source` exactly (order, duplicates, removals).

    Existing rows are reused for videos already in the playlist so their icon and
    upload status survive; rows whose video left the source are deleted (delete-orphan).
    """
    reusable: dict[str, list[Track]] = defaultdict(list)
    for track in sorted(playlist.tracks, key=lambda t: t.position):
        reusable[track.video_id].append(track)

    mirrored: list[Track] = []
    for position, info in enumerate(source):
        candidates = reusable[info.video_id]
        track = candidates.pop(0) if candidates else Track(video_id=info.video_id, status="pending")
        track.title = info.title
        track.artist = info.artist
        track.duration = info.duration
        track.thumbnail_url = info.thumbnail_url
        track.position = position
        if not info.available:
            track.status, track.error = "unavailable", UNAVAILABLE_MESSAGE
        elif track.status == "unavailable":
            track.status, track.error = "pending", None
        mirrored.append(track)

    playlist.tracks = mirrored
```

```python
import asyncio
import logging
import random
from collections.abc import Awaitable, Callable, Sequence
from dataclasses import dataclass
from typing import Literal

import httpx
from sqlalchemy import func, select, update
from sqlalchemy.orm import Session, sessionmaker

from app.db.models import Playlist, Track, UploadedMedia
from app.sync.mirror import mirror_tracks
from app.sync.ports import IconChooser, MusicSource, YotoGateway
from app.sync.progress import ProgressCallback, SyncProgress
from app.timeutil import utcnow
from app.yoto.content import MAX_CHAPTERS, ContentTrack, build_content
from app.yoto.errors import AuthRequired, ContentNotFound, YotoError
from app.yoto.models import UploadedAudio
from app.youtube.models import DownloadFailed, TrackUnavailable

log = logging.getLogger(__name__)

TRANSIENT_ERRORS = (DownloadFailed, YotoError, httpx.HTTPError, OSError)
INTERRUPTED_MESSAGE = "Interrupted (the app was restarted)"


class SyncAlreadyRunning(Exception):
    """A sync for this playlist is already in progress."""


class SyncError(Exception):
    """A sync could not complete; the message is shown to the user."""


@dataclass(frozen=True)
class SyncResult:
    status: Literal["ok", "partial", "error"]
    uploaded: int = 0
    failed: int = 0
    message: str | None = None


def _no_progress(_progress: SyncProgress) -> None:
    return None


Operation = Callable[[int, ProgressCallback], Awaitable[SyncResult]]


class SyncEngine:
    """Mirrors a playlist source into a Yoto playlist."""

    def __init__(
        self,
        sessions: sessionmaker[Session],
        music: MusicSource,
        yoto: YotoGateway,
        icons: IconChooser,
        *,
        rng: random.Random | None = None,
        concurrency: int = 2,
        retry_delays: Sequence[float] = (2.0, 5.0, 15.0),
        sleep: Callable[[float], Awaitable[None]] = asyncio.sleep,
    ) -> None:
        self._sessions = sessions
        self._music = music
        self._yoto = yoto
        self._icons = icons
        self._rng = rng or random.Random()
        self._concurrency = concurrency
        self._retry_delays = tuple(retry_delays)
        self._sleep = sleep
        self._lock = asyncio.Lock()  # one sync at a time, app-wide
        self._running: set[int] = set()

    def is_running(self, playlist_id: int) -> bool:
        return playlist_id in self._running

    async def sync(
        self, playlist_id: int, progress: ProgressCallback = _no_progress
    ) -> SyncResult:
        """Fetch the source, upload what is missing and rewrite the Yoto playlist."""
        return await self._run(playlist_id, progress, self._sync)

    async def rebuild(
        self, playlist_id: int, progress: ProgressCallback = _no_progress
    ) -> SyncResult:
        """Rewrite the Yoto playlist (title, order, shuffle, icons) without fetching or uploading."""
        return await self._run(playlist_id, progress, self._rebuild)

    async def _run(self, playlist_id: int, progress: ProgressCallback, operation: Operation) -> SyncResult:
        if playlist_id in self._running:
            raise SyncAlreadyRunning(playlist_id)
        self._running.add(playlist_id)
        try:
            async with self._lock:
                self._set_status(playlist_id, "running", None, touch=False)
                try:
                    result = await operation(playlist_id, progress)
                except AuthRequired as exc:
                    self._set_status(playlist_id, "error", str(exc))
                    progress(SyncProgress(playlist_id, "error", message=str(exc)))
                    raise
                except Exception as exc:
                    log.exception("Sync of playlist %s failed", playlist_id)
                    self._set_status(playlist_id, "error", str(exc))
                    progress(SyncProgress(playlist_id, "error", message=str(exc)))
                    return SyncResult("error", message=str(exc))
                self._set_status(playlist_id, result.status, result.message)
                progress(SyncProgress(playlist_id, "done", message=result.message))
                return result
        finally:
            self._running.discard(playlist_id)

    async def _sync(self, playlist_id: int, progress: ProgressCallback) -> SyncResult:
        with self._sessions() as session:
            playlist = self._get(session, playlist_id)
            source_type, source_url = playlist.source_type, playlist.source_url

        if source_type == "youtube":
            progress(SyncProgress(playlist_id, "fetching"))
            info = await self._music.get_playlist(source_url or "")
            if not info.tracks:
                raise SyncError("The YouTube Music playlist is empty or private")
            with self._sessions.begin() as session:
                playlist = self._get(session, playlist_id)
                mirror_tracks(playlist, info.tracks)
                if not playlist.cover_url:
                    playlist.cover_url = info.thumbnail_url

        uploaded = await self._upload_missing(playlist_id, progress)
        await self._assign_icons(playlist_id, progress)
        await self._ensure_cover(playlist_id)
        sent = await self._save_content(playlist_id, progress)
        return self._outcome(playlist_id, sent, uploaded)

    async def _rebuild(self, playlist_id: int, progress: ProgressCallback) -> SyncResult:
        sent = await self._save_content(playlist_id, progress)
        return self._outcome(playlist_id, sent, uploaded=0)

    async def _upload_missing(self, playlist_id: int, progress: ProgressCallback) -> int:
        with self._sessions.begin() as session:
            tracks = session.scalars(
                select(Track).where(Track.playlist_id == playlist_id).order_by(Track.position)
            ).all()
            cached = set(
                session.scalars(
                    select(UploadedMedia.video_id).where(
                        UploadedMedia.video_id.in_({t.video_id for t in tracks})
                    )
                )
            )
            todo: dict[str, str] = {}  # video_id -> title, each video transferred once
            for track in tracks:
                if track.video_id in cached:
                    if track.status != "unavailable":
                        track.status, track.error = "uploaded", None
                elif track.status != "unavailable":
                    todo.setdefault(track.video_id, track.title)

        total = len(todo)
        done = 0
        uploaded = 0
        semaphore = asyncio.Semaphore(self._concurrency)

        async def transfer(video_id: str, title: str) -> None:
            nonlocal done, uploaded
            async with semaphore:
                progress(SyncProgress(playlist_id, "uploading", done, total, title))
                try:
                    media = await self._with_retries(lambda: self._transfer(video_id))
                except AuthRequired:
                    raise
                except TrackUnavailable as exc:
                    self._set_track_status(playlist_id, video_id, "unavailable", str(exc))
                except Exception as exc:
                    log.warning("Could not transfer %s: %s", video_id, exc)
                    self._set_track_status(playlist_id, video_id, "error", str(exc))
                else:
                    self._store_media(playlist_id, video_id, media)
                    uploaded += 1
                done += 1
                progress(SyncProgress(playlist_id, "uploading", done, total, title))

        try:
            async with asyncio.TaskGroup() as group:
                for video_id, title in todo.items():
                    group.create_task(transfer(video_id, title))
        except* AuthRequired as errors:
            raise errors.exceptions[0] from None
        return uploaded

    async def _transfer(self, video_id: str) -> UploadedAudio:
        audio = await self._music.download_audio(video_id)
        try:
            return await self._yoto.upload_audio(audio.path, audio.mime)
        finally:
            audio.path.unlink(missing_ok=True)

    async def _with_retries(
        self, operation: Callable[[], Awaitable[UploadedAudio]]
    ) -> UploadedAudio:
        delays: tuple[float | None, ...] = (*self._retry_delays, None)
        for delay in delays:
            try:
                return await operation()
            except (AuthRequired, TrackUnavailable):
                raise
            except TRANSIENT_ERRORS as exc:
                if delay is None:
                    raise
                log.warning("Transfer failed (%s), retrying in %ss", exc, delay)
                await self._sleep(delay)
        raise AssertionError("unreachable")

    async def _assign_icons(self, playlist_id: int, progress: ProgressCallback) -> None:
        with self._sessions() as session:
            playlist = self._get(session, playlist_id)
            color = playlist.color
            pending = [
                (t.id, t.title, t.artist)
                for t in playlist.tracks
                if t.icon_id is None and not t.icon_manual
            ]
        for index, (track_id, title, artist) in enumerate(pending, start=1):
            progress(SyncProgress(playlist_id, "icons", index, len(pending), title))
            choice = await self._icons.pick(title, artist, color)
            if choice is None:
                continue
            with self._sessions.begin() as session:
                track = session.get(Track, track_id)
                if track is not None and not track.icon_manual:
                    track.icon_id, track.icon_url = choice.media_id, choice.url

    async def _ensure_cover(self, playlist_id: int) -> None:
        with self._sessions() as session:
            playlist = self._get(session, playlist_id)
            cover_url, uploaded_cover = playlist.cover_url, playlist.yoto_cover_url
        if not cover_url or uploaded_cover:
            return
        try:
            yoto_cover = await self._yoto.upload_cover_from_url(cover_url)
        except AuthRequired:
            raise
        except Exception:
            log.warning("Cover upload failed for playlist %s", playlist_id, exc_info=True)
            return
        with self._sessions.begin() as session:
            self._get(session, playlist_id).yoto_cover_url = yoto_cover

    async def _save_content(self, playlist_id: int, progress: ProgressCallback) -> int:
        progress(SyncProgress(playlist_id, "saving"))
        with self._sessions() as session:
            playlist = self._get(session, playlist_id)
            rows = session.execute(
                select(Track, UploadedMedia)
                .join(UploadedMedia, UploadedMedia.video_id == Track.video_id)
                .where(Track.playlist_id == playlist_id)
                .order_by(Track.position)
            ).all()
            title, shuffle = playlist.title, playlist.shuffle
            card_id, cover = playlist.yoto_card_id, playlist.yoto_cover_url
            tracks = [
                ContentTrack(t.title, m.sha256, m.duration, m.file_size, m.channels, m.format, t.icon_id)
                for t, m in rows
            ]
        if not tracks:
            raise SyncError("No track could be sent to Yoto")
        if shuffle:
            self._rng.shuffle(tracks)

        body = build_content(title, tracks, shuffle=shuffle, cover_url=cover)
        try:
            new_card_id = await self._yoto.save_content(body, card_id)
        except ContentNotFound:
            log.info("Yoto playlist %s no longer exists; creating a new one", card_id)
            new_card_id = await self._yoto.save_content(body, None)

        with self._sessions.begin() as session:
            self._get(session, playlist_id).yoto_card_id = new_card_id
        return len(tracks)

    def _outcome(self, playlist_id: int, sent: int, uploaded: int) -> SyncResult:
        with self._sessions() as session:
            missing = session.scalar(
                select(func.count())
                .select_from(Track)
                .outerjoin(UploadedMedia, UploadedMedia.video_id == Track.video_id)
                .where(Track.playlist_id == playlist_id, UploadedMedia.video_id.is_(None))
            ) or 0
        status: Literal["ok", "partial"] = "partial" if missing or sent > MAX_CHAPTERS else "ok"
        return SyncResult(status, uploaded=uploaded, failed=missing)

    def _store_media(self, playlist_id: int, video_id: str, media: UploadedAudio) -> None:
        with self._sessions.begin() as session:
            session.merge(
                UploadedMedia(
                    video_id=video_id,
                    sha256=media.sha256,
                    duration=media.duration,
                    file_size=media.file_size,
                    channels=media.channels,
                    format=media.format,
                )
            )
            session.execute(
                update(Track)
                .where(Track.playlist_id == playlist_id, Track.video_id == video_id)
                .values(status="uploaded", error=None)
            )

    def _set_track_status(self, playlist_id: int, video_id: str, status: str, error: str) -> None:
        with self._sessions.begin() as session:
            session.execute(
                update(Track)
                .where(Track.playlist_id == playlist_id, Track.video_id == video_id)
                .values(status=status, error=error[:500])
            )

    def _set_status(
        self, playlist_id: int, status: str, error: str | None, *, touch: bool = True
    ) -> None:
        with self._sessions.begin() as session:
            playlist = session.get(Playlist, playlist_id)
            if playlist is None:
                return
            playlist.last_sync_status = status
            playlist.last_sync_error = error[:1000] if error else None
            if touch:
                playlist.last_sync_at = utcnow()

    @staticmethod
    def _get(session: Session, playlist_id: int) -> Playlist:
        playlist = session.get(Playlist, playlist_id)
        if playlist is None:
            raise SyncError(f"Playlist {playlist_id} does not exist")
        return playlist


def reset_interrupted(sessions: sessionmaker[Session]) -> int:
    """Mark playlists left 'running' by a previous process as failed. Returns how many."""
    with sessions.begin() as session:
        result = session.execute(
            update(Playlist)
            .where(Playlist.last_sync_status == "running")
            .values(last_sync_status="error", last_sync_error=INTERRUPTED_MESSAGE)
        )
        return int(result.rowcount or 0)
```

```python
import asyncio
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager
from typing import Any


class EventBroker:
    """In-memory pub/sub feeding the SSE endpoint. Slow subscribers lose events, never block."""

    def __init__(self, max_queue: int = 100) -> None:
        self._max_queue = max_queue
        self._subscribers: set[asyncio.Queue[dict[str, Any]]] = set()

    def publish(self, event: dict[str, Any]) -> None:
        for queue in list(self._subscribers):
            try:
                queue.put_nowait(event)
            except asyncio.QueueFull:
                pass

    @asynccontextmanager
    async def subscribe(self) -> AsyncIterator[asyncio.Queue[dict[str, Any]]]:
        queue: asyncio.Queue[dict[str, Any]] = asyncio.Queue(maxsize=self._max_queue)
        self._subscribers.add(queue)
        try:
            yield queue
        finally:
            self._subscribers.discard(queue)
```

```python
import logging
from collections.abc import Awaitable, Callable

from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.triggers.cron import CronTrigger
from sqlalchemy import select
from sqlalchemy.orm import Session, sessionmaker

from app.db.models import Playlist
from app.sync.engine import SyncAlreadyRunning, SyncResult
from app.yoto.errors import AuthRequired

log = logging.getLogger(__name__)

JOB_ID = "scheduled-sync"


async def run_scheduled_sync(
    sessions: sessionmaker[Session], sync: Callable[[int], Awaitable[SyncResult]]
) -> None:
    with sessions() as session:
        playlist_ids = session.scalars(
            select(Playlist.id).where(Playlist.auto_sync.is_(True)).order_by(Playlist.id)
        ).all()
    log.info("Scheduled sync of %d playlist(s)", len(playlist_ids))
    for playlist_id in playlist_ids:
        try:
            await sync(playlist_id)
        except SyncAlreadyRunning:
            continue
        except AuthRequired:
            log.warning("Yoto session expired; stopping the scheduled sync")
            return


def create_scheduler(
    cron: str, tz: str, job: Callable[[], Awaitable[None]]
) -> AsyncIOScheduler:
    scheduler = AsyncIOScheduler(timezone=tz)
    scheduler.add_job(
        job,
        CronTrigger.from_crontab(cron, timezone=tz),
        id=JOB_ID,
        max_instances=1,
        coalesce=True,
        misfire_grace_time=3600,
    )
    return scheduler
```

```python
@dataclass
class Services:
    settings: Settings
    sessions: sessionmaker[Session]
    auth: YotoAuth
    yoto: YotoClient
    music: YouTubeMusicSource
    catalog: IconCatalog
    engine: SyncEngine
    broker: EventBroker
    settings_store: DbSettingsStore
    icon_ai_enabled: bool
    _tasks: set[asyncio.Task[None]] = field(default_factory=set)

    def start_sync(self, playlist_id: int, *, rebuild: bool = False) -> None:
        if self.engine.is_running(playlist_id):
            raise SyncAlreadyRunning(playlist_id)
        task = asyncio.create_task(self._sync(playlist_id, rebuild))
        self._tasks.add(task)
        task.add_done_callback(self._tasks.discard)

    async def scheduled_sync(self) -> None:
        await run_scheduled_sync(self.sessions, self._sync_and_notify)

    async def _sync(self, playlist_id: int, rebuild: bool) -> None:
        try:
            if rebuild:
                await self.engine.rebuild(playlist_id, self._publish_progress)
            else:
                await self.engine.sync(playlist_id, self._publish_progress)
        except AuthRequired:
            self.broker.publish({"type": "auth_required"})
        except SyncAlreadyRunning:
            return
        self.broker.publish({"type": "playlist_updated", "playlist_id": playlist_id})

    async def _sync_and_notify(self, playlist_id: int) -> SyncResult:
        try:
            return await self.engine.sync(playlist_id, self._publish_progress)
        except AuthRequired:
            self.broker.publish({"type": "auth_required"})
            raise
        finally:
            self.broker.publish({"type": "playlist_updated", "playlist_id": playlist_id})

    def _publish_progress(self, progress: SyncProgress) -> None:
        self.broker.publish({"type": "progress", **progress.to_dict()})


async def build_services(settings: Settings, stack: AsyncExitStack) -> Services:
    settings.data_dir.mkdir(parents=True, exist_ok=True)
    shutil.rmtree(settings.tmp_dir, ignore_errors=True)  # leftovers of an interrupted sync
    settings.tmp_dir.mkdir(parents=True)

    run_migrations(settings.database_url)
    db_engine = make_engine(settings.database_url)
    stack.callback(db_engine.dispose)
    sessions = make_session_factory(db_engine)
    if reset := reset_interrupted(sessions):
        log.info("Marked %d interrupted sync(s) as failed", reset)

    http = await stack.enter_async_context(
        httpx.AsyncClient(timeout=httpx.Timeout(60.0, connect=10.0), follow_redirects=True)
    )
    auth = YotoAuth(
        settings.yoto_client_id,
        settings.yoto_auth_url,
        settings.redirect_uri,
        DbTokenStore(sessions),
        http,
    )
    yoto = YotoClient(auth, http, settings.yoto_api_url)
    music = YouTubeMusicSource(settings.tmp_dir)
    catalog = IconCatalog(yoto)
    settings_store = DbSettingsStore(sessions)

    suggester = None
    if settings.anthropic_api_key:
        anthropic_client = AsyncAnthropic(api_key=settings.anthropic_api_key)
        stack.push_async_callback(anthropic_client.close)
        suggester = ClaudeKeywordSuggester(anthropic_client, settings.anthropic_model)

    picker = IconPicker(catalog, yoto, settings_store, suggester)
    engine = SyncEngine(sessions, music, yoto, picker)
    return Services(
        settings=settings,
        sessions=sessions,
        auth=auth,
        yoto=yoto,
        music=music,
        catalog=catalog,
        engine=engine,
        broker=EventBroker(),
        settings_store=settings_store,
        icon_ai_enabled=suggester is not None,
    )
```

```python
from sqlalchemy import select
from sqlalchemy.orm import Session

def _get(session: Session, playlist_id: int) -> Playlist:
    playlist = session.get(Playlist, playlist_id)
    if playlist is None:
        raise ApiProblem(404, "not_found", "Playlist not found")

def _summary(playlist: Playlist, services: Services) -> PlaylistSummary:
    return PlaylistSummary(
        id=playlist.id,
        title=playlist.title,
        source_type=playlist.source_type,
        source_url=playlist.source_url,

        syncing=services.engine.is_running(playlist.id),

def _detail(playlist: Playlist, services: Services) -> PlaylistDetail:
    return PlaylistDetail(
        **_summary(playlist, services).model_dump(),
        tracks=[TrackOut.model_validate(t) for t in playlist.tracks],
    )


def _infos(tracks: list[TrackIn]) -> list[TrackInfo]:
    return [TrackInfo(t.video_id, t.title, t.artist, t.duration, t.thumbnail_url) for t in tracks]


def _start(services: Services, playlist_id: int, *, rebuild: bool = False) -> None:
    try:
        services.start_sync(playlist_id, rebuild=rebuild)
    except SyncAlreadyRunning:
        pass  # the running sync will pick up the latest state on its next run


@router.get("", response_model=list[PlaylistSummary])
def list_playlists(services: Services = Depends(get_services)) -> list[PlaylistSummary]:
    with services.sessions() as session:
        playlists = session.scalars(select(Playlist).order_by(Playlist.created_at.desc())).all()
        return [_summary(p, services) for p in playlists]


@router.post("", response_model=PlaylistDetail, status_code=201)
def create_playlist(body: PlaylistCreate, services: Services = Depends(get_services)) -> PlaylistDetail:
    source_url = None
    if body.source_type == "youtube":
        source_url = f"https://music.youtube.com/playlist?list={parse_playlist_id(body.source_url or '')}"
    with services.sessions.begin() as session:
        playlist = Playlist(
            title=body.title,
            source_type=body.source_type,
            source_url=source_url,
            shuffle=body.shuffle,
            auto_sync=body.auto_sync and body.source_type == "youtube",
            color=body.color,
        )
        if body.source_type == "manual":
            mirror_tracks(playlist, _infos(body.tracks))
            playlist.cover_url = next((t.thumbnail_url for t in body.tracks if t.thumbnail_url), None)
        session.add(playlist)
        session.flush()
        detail = _detail(playlist, services)
    _start(services, detail.id)
    return detail


@router.get("/{playlist_id}", response_model=PlaylistDetail)
def get_playlist(playlist_id: int, services: Services = Depends(get_services)) -> PlaylistDetail:
    with services.sessions() as session:
        return _detail(_get(session, playlist_id), services)


@router.patch("/{playlist_id}", response_model=PlaylistDetail)
def update_playlist(
    playlist_id: int, body: PlaylistUpdate, services: Services = Depends(get_services)
) -> PlaylistDetail:
    with services.sessions.begin() as session:
        playlist = _get(session, playlist_id)
        changes = body.model_dump(exclude_unset=True, exclude_none=True)
        needs_rebuild = playlist.yoto_card_id is not None and any(
            changes.get(name, getattr(playlist, name)) != getattr(playlist, name)
            for name in ("title", "shuffle")
        )
        for name, value in changes.items():
            setattr(playlist, name, value)
        detail = _detail(playlist, services)
    if needs_rebuild:
        _start(services, playlist_id, rebuild=True)
    return detail


@router.delete("/{playlist_id}", status_code=204)
async def delete_playlist(
    playlist_id: int, delete_on_yoto: bool = False, services: Services = Depends(get_services)
) -> Response:
    if services.engine.is_running(playlist_id):
        raise SyncAlreadyRunning(playlist_id)
    with services.sessions() as session:
        card_id = _get(session, playlist_id).yoto_card_id
    if delete_on_yoto and card_id:
        await services.yoto.delete_content(card_id)
    with services.sessions.begin() as session:
        session.delete(_get(session, playlist_id))
    return Response(status_code=204)


@router.put("/{playlist_id}/tracks", response_model=PlaylistDetail)
def replace_tracks(
    playlist_id: int, tracks: list[TrackIn], services: Services = Depends(get_services)
) -> PlaylistDetail:
    if not tracks:
        raise ApiProblem(422, "validation_error", "A playlist needs at least one track")
    with services.sessions.begin() as session:
        playlist = _get(session, playlist_id)
        if playlist.source_type != "manual":
            raise ApiProblem(409, "not_manual", "Tracks of an imported playlist come from YouTube Music")
        mirror_tracks(playlist, _infos(tracks))
        session.flush()
        detail = _detail(playlist, services)
    _start(services, playlist_id)
    return detail


@router.patch("/{playlist_id}/tracks/{track_id}", response_model=TrackOut)
def set_track_icon(
    playlist_id: int,
    track_id: int,
    body: TrackIconUpdate,
    services: Services = Depends(get_services),
) -> TrackOut:
    with services.sessions.begin() as session:
        track = session.get(Track, track_id)
        if track is None or track.playlist_id != playlist_id:
            raise ApiProblem(404, "not_found", "Track not found")
        track.icon_id, track.icon_url, track.icon_manual = body.icon_id, body.icon_url, True
        has_card = track.playlist.yoto_card_id is not None
        result = TrackOut.model_validate(track)
    if has_card:
        _start(services, playlist_id, rebuild=True)
    return result


@router.post("/{playlist_id}/sync", response_model=Accepted, status_code=202)
def sync_playlist(playlist_id: int, services: Services = Depends(get_services)) -> Accepted:
    with services.sessions() as session:
        _get(session, playlist_id)
    services.start_sync(playlist_id)  # SyncAlreadyRunning → 409
    return Accepted()


@router.post("/{playlist_id}/reshuffle", response_model=Accepted, status_code=202)
def reshuffle_playlist(playlist_id: int, services: Services = Depends(get_services)) -> Accepted:
    with services.sessions() as session:
        if _get(session, playlist_id).yoto_card_id is None:
            raise ApiProblem(409, "not_synced", "Sync the playlist once before reshuffling")
    services.start_sync(playlist_id, rebuild=True)
    return Accepted()
```

```python
import logging
from collections.abc import AsyncIterator, Callable
from contextlib import AsyncExitStack, asynccontextmanager

from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

from app.api import auth, events, icons, playlists, search, settings as settings_api
from app.api.errors import register_error_handlers
from app.config import Settings, get_settings
from app.scheduler import create_scheduler
from app.services import Services, build_services

log = logging.getLogger(__name__)


def create_app(
    settings: Settings | None = None,
    services_factory: Callable[[Settings], Services] | None = None,
) -> FastAPI:
    settings = settings or get_settings()
    logging.basicConfig(
        level=settings.log_level.upper(), format="%(asctime)s %(levelname)s %(name)s: %(message)s"
    )

    @asynccontextmanager
    async def lifespan(app: FastAPI) -> AsyncIterator[None]:
        if services_factory is not None:  # tests
            app.state.services = services_factory(settings)
            yield
            return
        async with AsyncExitStack() as stack:
            services = await build_services(settings, stack)
            app.state.services = services
            scheduler = create_scheduler(settings.sync_cron, settings.tz, services.scheduled_sync)
            scheduler.start()
            stack.callback(scheduler.shutdown, wait=False)
            if not settings.yoto_client_id:
                log.warning("YOTO_CLIENT_ID is not set: Yoto login is disabled")
            yield

    app = FastAPI(title="Yotube", lifespan=lifespan)
    app.state.settings = settings
    register_error_handlers(app)

    @app.get("/api/health")
    async def health() -> dict[str, str]:
        return {"status": "ok"}

    for router in (auth.router, search.router, playlists.router, icons.router,
                   settings_api.router, events.router):
        app.include_router(router)

    if settings.static_dir and settings.static_dir.is_dir():
        app.mount("/", StaticFiles(directory=settings.static_dir, html=True), name="ui")
    return app
```

`frontend/src/lib/format.ts`

```ts
import type { Color } from './types'

export const COLORS: Record<Color, string> = {
  orange: '#F26B3A',
  yellow: '#F5B82E',
  blue: '#3B82F6',
  green: '#22A06B',
  pink: '#EC4899',
  purple: '#8B5CF6',
  red: '#E5484D',
  teal: '#14B8A6',
}

export const COLOR_NAMES = Object.keys(COLORS) as Color[]

export function formatDuration(seconds: number | null): string {
  if (seconds == null) return ''
  const total = Math.round(seconds)
  const minutes = Math.floor(total / 60)
  return `${minutes}:${String(total % 60).padStart(2, '0')}`
}

/** Backend datetimes are naive UTC ISO strings. */
export function formatDate(iso: string | null, locale: string): string {
  if (!iso) return ''
  const date = new Date(/[zZ]|[+-]\d\d:\d\d$/.test(iso) ? iso : `${iso}Z`)
  return new Intl.DateTimeFormat(locale, { dateStyle: 'medium', timeStyle: 'short' }).format(date)
}
```

```ts
import { describe, expect, it } from 'vitest'
import { COLOR_NAMES, formatDate, formatDuration } from './format'

describe('formatDuration', () => {
  it('formats minutes and seconds', () => {
    expect(formatDuration(125)).toBe('2:05')
    expect(formatDuration(59.6)).toBe('1:00')
    expect(formatDuration(null)).toBe('')
  })
})

describe('formatDate', () => {
  it('treats naive timestamps as UTC', () => {
    expect(formatDate('2026-10-12T03:00:00', 'en-GB')).toBe(formatDate('2026-10-12T03:00:00Z', 'en-GB'))
    expect(formatDate(null, 'en')).toBe('')
  })
})

it('exposes the eight playlist colours', () => {
  expect(COLOR_NAMES).toHaveLength(8)
})
```

```ts
import en from './locales/en.json'
import fr from './locales/fr.json'
import ru from './locales/ru.json'
import type { Locale } from './types'

type Dict = { [key: string]: string | Dict }
type Params = Record<string, string | number>

export const LOCALES: Record<Locale, Dict> = { en, fr, ru }
export const LOCALE_NAMES: Record<Locale, string> = { en: 'English', fr: 'Français', ru: 'Русский' }

const STORAGE_KEY = 'yotube.locale'

function isLocale(value: unknown): value is Locale {
  return typeof value === 'string' && value in LOCALES
}

function storedLocale(): Locale | null {
  try {
    const value = localStorage.getItem(STORAGE_KEY)
    return isLocale(value) ? value : null
  } catch {
    return null
  }
}

function detectLocale(): Locale {
  const stored = storedLocale()
  if (stored) return stored
  const browser = typeof navigator === 'undefined' ? 'en' : navigator.language.slice(0, 2)
  return isLocale(browser) ? browser : 'en'
}

export const i18n = $state({ locale: detectLocale() })

export function hasStoredLocale(): boolean {
  return storedLocale() !== null
}

export function setLocale(locale: Locale): void {
  i18n.locale = locale
  document.documentElement.lang = locale
  try {
    localStorage.setItem(STORAGE_KEY, locale)
  } catch {
    // Private browsing: the choice simply isn't remembered.
  }
}

function lookup(dict: Dict, key: string): string | undefined {
  let current: string | Dict | undefined = dict
  for (const part of key.split('.')) {
    if (typeof current !== 'object' || current === null) return undefined
    current = current[part]
  }
  return typeof current === 'string' ? current : undefined
}

export function translate(locale: Locale, key: string, params: Params = {}): string {
  const template = lookup(LOCALES[locale], key) ?? lookup(LOCALES.en, key) ?? key
  return template.replace(/\{(\w+)\}/g, (match, name: string) =>
    name in params ? String(params[name]) : match,
  )
}

export function tnFor(locale: Locale, key: string, count: number, params: Params = {}): string {
  const category = new Intl.PluralRules(locale).select(count)
  const pluralKey = lookup(LOCALES[locale], `${key}.${category}`) ? category : 'other'
  return translate(locale, `${key}.${pluralKey}`, { count, ...params })
}

/** Translate `key` in the current locale (reactive inside components). */
export function t(key: string, params?: Params): string {
  return translate(i18n.locale, key, params)
}

/** Translate a plural key (`key.one|few|many|other`) for `count`. */
export function tn(key: string, count: number, params?: Params): string {
  return tnFor(i18n.locale, key, count, params)
}

export function flattenKeys(dict: Dict, prefix = ''): string[] {
  return Object.entries(dict).flatMap(([key, value]) =>
    typeof value === 'string' ? [`${prefix}${key}`] : flattenKeys(value, `${prefix}${key}.`),
  )
}
```

```ts
type Params = Record<string, string>

export type Route =
  | { name: 'library'; params: Params }
  | { name: 'new'; params: Params }
  | { name: 'playlist'; id: number; params: Params }
  | { name: 'settings'; params: Params }

export function parseHash(hash: string): Route {
  const [path, query = ''] = hash.replace(/^#/, '').split('?')
  const params = Object.fromEntries(new URLSearchParams(query))
  if (path === '/new') return { name: 'new', params }
  if (path === '/settings') return { name: 'settings', params }
  const match = /^\/playlists\/(\d+)$/.exec(path)
  if (match) return { name: 'playlist', id: Number(match[1]), params }
  return { name: 'library', params }
}

export const router = $state<{ route: Route }>({ route: parseHash(window.location.hash) })

export function startRouter(): void {
  window.addEventListener('hashchange', () => {
    router.route = parseHash(window.location.hash)
    window.scrollTo(0, 0)
  })
}

export function navigate(path: string): void {
  window.location.hash = path
}
```

```ts
export class ApiError extends Error {
  constructor(
    public readonly status: number,
    public readonly code: string,
    message: string,
  ) {
    super(message)
  }
}

async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
  let response: Response
  try {
    response = await fetch(path, {
      method,
      headers: body === undefined ? {} : { 'Content-Type': 'application/json' },
      body: body === undefined ? undefined : JSON.stringify(body),
    })
  } catch {
    throw new ApiError(0, 'network', 'Network error')
  }
  if (!response.ok) {
    let data: { detail?: unknown; code?: string } = {}
    try {
      data = await response.json()
    } catch {
      // Not JSON (e.g. a proxy error page).
    }
    const message = typeof data.detail === 'string' ? data.detail : response.statusText
    throw new ApiError(response.status, data.code ?? 'generic', message)
  }
  if (response.status === 204) return undefined as T
  return (await response.json()) as T
}
```

`frontend/src/lib/events.svelte.ts`

```ts
import type { ProgressEvent, ServerEvent } from './types'

export const live = $state({
  progress: {} as Record<number, ProgressEvent>,
  /** Incremented whenever server data may have changed; pages refetch on change. */
  version: 0,
  authRequired: false,
})

export function handleEvent(event: ServerEvent): void {
  switch (event.type) {
    case 'progress':
      if (event.phase === 'done' || event.phase === 'error') {
        delete live.progress[event.playlist_id]
      } else {
        live.progress[event.playlist_id] = event
      }
      break
    case 'playlist_updated':
      live.version += 1
      break
    case 'auth_required':
      live.authRequired = true
      break
  }
}

export function connectEvents(): () => void {
  const source = new EventSource('/api/events')
  source.onmessage = (message) => handleEvent(JSON.parse(message.data) as ServerEvent)
  source.onopen = () => {
    live.version += 1 // refetch after a reconnection
  }
  return () => source.close()
}
```

```svelte
    busy = true
    error = null
    preview = null
    try {
      preview = await api.previewPlaylist(url.trim())
      title = preview.title
    } catch (e) {
      error = errorMessage(e)
    } finally {
      busy = false
    }

  function move(index: number, delta: number) {
    const target = index + delta
    if (target < 0 || target >= basket.length) return
    const next = [...basket]
    ;[next[index], next[target]] = [next[target], next[index]]
    basket = next
  }

  async function create() {
    busy = true
    error = null
    try {
      const playlist =
        tab === 'import'
          ? await api.createPlaylist({
              title: title.trim(),
              source_type: 'youtube',
              source_url: url.trim(),
              shuffle,
              auto_sync: autoSync,
              color,
            })
          : await api.createPlaylist({
              title: title.trim(),
              source_type: 'manual',
              tracks: basket.map(({ video_id, title, artist, duration, thumbnail_url }) => ({
                video_id,
                title,
                artist,
                duration,
                thumbnail_url,
              })),
              shuffle,
              auto_sync: false,
              color,
            })
      navigate(`/playlists/${playlist.id}`)
    } catch (e) {
      error = errorMessage(e)
      busy = false
    }
  }
```

```svelte
<script lang="ts">
  import ColorPicker from '../components/ColorPicker.svelte'
  import IconPicker from '../components/IconPicker.svelte'
  import PixelIcon from '../components/PixelIcon.svelte'
  import StatusBadge from '../components/StatusBadge.svelte'

  import { errorMessage } from '../lib/errors'
  import { live } from '../lib/events.svelte'
  import { COLORS, formatDate, formatDuration } from '../lib/format'
  import { i18n, t } from '../lib/i18n.svelte'
  import { navigate } from '../lib/router.svelte'
  import type { Icon, PlaylistDetail, PlaylistUpdate, Track, TrackIn, TrackInfo } from '../lib/types'

  let { id }: { id: number } = $props()

  let playlist = $state<PlaylistDetail | null>(null)
  let error = $state<string | null>(null)
  let draft = $state<TrackIn[] | null>(null) // unsaved edits of a hand-picked playlist
  let adding = $state(false)
  let iconTrack = $state<Track | null>(null)
  let confirmDelete = $state(false)
  let deleteOnYoto = $state(false)
  let title = $state('')
  let dragIndex: number | null = null

  const progress = $derived(live.progress[id])
  const manual = $derived(playlist?.source_type === 'manual')
  const status = $derived(playlist?.syncing || progress ? 'running' : (playlist?.last_sync_status ?? null))
  const draftIds = $derived(new Set((draft ?? []).map((t) => t.video_id)))

  async function load() {
    try {
      playlist = await api.getPlaylist(id)
      title = playlist.title
      error = null
    } catch (e) {
      error = errorMessage(e)
    }
  }

  $effect(() => {
    void live.version
    load()
  })

  async function run(action: () => Promise<unknown>) {
    error = null
    try {
      await action()
      await load()
    } catch (e) {
      error = errorMessage(e)
    }
  }

  const update = (body: PlaylistUpdate) => run(() => api.updatePlaylist(id, body))

  function asTrackIn(track: Track | TrackInfo): TrackIn {
    const { video_id, title, artist, duration, thumbnail_url } = track
    return { video_id, title, artist, duration, thumbnail_url }
  }

  function editTracks(change: (tracks: TrackIn[]) => TrackIn[]) {
    draft = change(draft ?? playlist!.tracks.map(asTrackIn))
  }

  function moveTrack(from: number, to: number) {
    editTracks((tracks) => {
      const next = [...tracks]
      const [item] = next.splice(from, 1)
      next.splice(to, 0, item)
      return next
    })
  }

  async function saveTracks() {
    if (!draft) return
    const tracks = draft
    await run(() => api.replaceTracks(id, tracks))
    draft = null
    adding = false
  }

  async function pickIcon(icon: Icon) {
    const track = iconTrack
    if (track) await run(() => api.setTrackIcon(id, track.id, icon))
  }

  async function remove() {
    try {
      await api.deletePlaylist(id, deleteOnYoto)
      navigate('/')
    } catch (e) {
      error = errorMessage(e)
      confirmDelete = false
    }
  }

  const rows: (Track | TrackIn)[] = $derived(draft ?? playlist?.tracks ?? [])
</script>
```

```svelte
  let settings = $state<AppSettings | null>(null)
  let error = $state<string | null>(null)

    try {
      settings = await api.getSettings()
      live.authRequired = settings.yoto_configured && !settings.yoto_connected
    } catch (e) {

    await load()

  }

    load()
  })
```

```dockerfile
# syntax=docker/dockerfile:1.7

FROM node:22-alpine AS ui
WORKDIR /ui
COPY frontend/package.json frontend/package-lock.json ./

COPY frontend/ ./
RUN npm run build

# yt-dlp needs a JavaScript runtime to solve YouTube's player challenges.
FROM denoland/deno:bin-2.5.6 AS deno

FROM python:3.13-slim AS runtime
ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    PIP_NO_CACHE_DIR=1 \
    PIP_DISABLE_PIP_VERSION_CHECK=1 \
    DATA_DIR=/data \
    STATIC_DIR=/app/static \
    PORT=8080 \
    TZ=Europe/Paris \

RUN apt-get update \
    && apt-get install -y --no-install-recommends tzdata \
    && rm -rf /var/lib/apt/lists/* \
    && useradd --create-home --uid 1000 yotube \
    && mkdir -p /data \
    && chown yotube:yotube /data

COPY --from=deno /deno /usr/local/bin/deno

WORKDIR /app
COPY backend/pyproject.toml ./
COPY backend/app ./app
RUN pip install . && rm -rf /root/.cache

COPY --from=ui /ui/dist ./static
COPY --chmod=755 docker/entrypoint.sh /usr/local/bin/entrypoint.sh

USER yotube
VOLUME ["/data"]
EXPOSE 8080
HEALTHCHECK --interval=30s --timeout=5s --start-period=30s --retries=3 \
  CMD python -c "import os, urllib.request; urllib.request.urlopen(f'http://127.0.0.1:{os.environ.get(\"PORT\", \"8080\")}/api/health', timeout=4)"
ENTRYPOINT ["entrypoint.sh"]
```

If the `denoland/deno:bin-2.5.6` tag does not exist when you build, use the most recent `bin-2.x.y` tag listed on Docker Hub (pin an exact version, never `latest`).

- [ ] **Step 2: Write the entrypoint** — `docker/entrypoint.sh`

```sh
#!/bin/sh
set -eu

# YouTube changes often; a fresh yt-dlp avoids most download failures.
if [ "${YTDLP_AUTO_UPDATE:-true}" = "true" ]; then
  echo "Updating yt-dlp..."
  pip install --user --quiet --upgrade "yt-dlp[default]" \
    || echo "yt-dlp update failed; using the version bundled in the image"
fi

exec uvicorn app.main:create_app --factory \
  --host 0.0.0.0 --port "${PORT:-8080}" --proxy-headers --forwarded-allow-ips='*'
```

````markdown
Yotube is a small self-hosted web app (one Docker container) for parents with a Yoto player:

- **Import** a YouTube Music playlist from its link, or **pick songs** one by one with search.
- The playlist lands in your **Yoto library**: play it from the Yoto app, or link it to a blank
  **Make Your Own card**.
- Imported playlists stay **mirrored**: songs added, removed or reordered on YouTube Music follow,
  on demand or every night.
- **Shuffle** mode: the player shuffles songs at every play, and the app order changes at every sync.
- Every song gets a **16×16 pixel icon** on the player screen, picked from Yoto's icon library
  (smarter with an optional Claude API key).
- Interface in **English, French and Russian**.

> Yotube is a personal project, not affiliated with Yoto or YouTube.

## How it works

```
YouTube Music ──search / playlist──▶ Yotube ──audio upload──▶ Yoto API ──▶ Yoto library
                 (ytmusicapi, yt-dlp)   │                       (transcoding)    ├─ Yoto app
                                        └─ SQLite in /data                       └─ MYO card
```

Yotube downloads the audio of each new song once, uploads it to Yoto (Yoto converts it for its
players), then rewrites the Yoto playlist. Songs already uploaded are never downloaded again.

## Quick start

### 1. Create a Yoto developer app (once)

1. Go to <https://dashboard.yoto.dev> and sign in with your Yoto account.
2. Create an application (public client).
3. Add the allowed callback URL: `http://localhost:8080/auth/callback`.
4. Copy the **Client ID**.

### 2. Configure

```bash
git clone https://github.com/kinsoi/yotube.git
cd yotube
cp .env.example .env
```

Edit `.env` and set `YOTO_CLIENT_ID`. Optionally set `ANTHROPIC_API_KEY` for smarter icons.

### 3. Run

```bash
docker compose up -d
```

This uses the published image `ghcr.io/kinsoi/yotube`. To build it yourself instead:
`docker compose up -d --build`.

### 4. Connect and create

1. Open <http://localhost:8080> **on the machine running Docker** and go to **Settings → Connect to Yoto**.
   (The Yoto login redirects to `localhost`; after that, you can use Yotube from any device on your network.)
2. Click **New playlist**, paste a YouTube Music playlist link (public or unlisted), and create it.
3. Watch the progress; after a few minutes the playlist is in the Yoto app.
4. To use a card: in the Yoto app, open *Make Your Own*, pick the playlist and link it to a blank card.
   The card follows the playlist forever, even after syncs.

## Configuration

| Variable | Default | Description |
|---|---|---|
| `YOTO_CLIENT_ID` | — | **Required.** Client ID from dashboard.yoto.dev |
| `PUBLIC_URL` | `http://localhost:8080` | URL used to open Yotube; the callback `PUBLIC_URL/auth/callback` must be registered at Yoto |
| `ANTHROPIC_API_KEY` | empty | Enables icon picking by Claude (a few cents per month) |
| `ANTHROPIC_MODEL` | `claude-haiku-5-5` | Model used for icon picking |
| `SYNC_CRON` | `0 3 * * *` | Nightly sync schedule (cron) |
| `TZ` | `Europe/Paris` | Timezone of the schedule |
| `PORT` | `8080` | HTTP port |
| `YTDLP_AUTO_UPDATE` | `true` | Update yt-dlp at container start |
| `LOG_LEVEL` | `INFO` | Log verbosity |

Data (database and Yoto session) lives in the `yotube-data` Docker volume.

```bash
docker compose pull && docker compose up -d
```

## Troubleshooting

- **"Sync failed" with download errors** — YouTube changed something. Restart the container
  (`docker compose restart`) so yt-dlp updates itself, then sync again.
- **"Could not read playlist"** — the playlist must be public or unlisted. Private playlists and
  "Liked music" cannot be read.
- **Yotube asks to reconnect** — the Yoto session expired or was revoked. Reconnect from Settings,
  from the machine running Docker.
- **A song shows "Unavailable on YouTube"** — the video was removed or blocked. If it was already on
  your Yoto, Yotube keeps it there.
- Logs: `docker compose logs -f yotube`.

## Security and fair use

- Yotube has **no login of its own**. Keep it on your home network; never expose it to the internet.
- Downloading audio from YouTube may conflict with YouTube's Terms of Service. Use Yotube for
  personal, family use only, with content you are allowed to listen to.

## Development

```bash
# Backend (Python 3.12+)
cd backend && python3 -m venv .venv && .venv/bin/pip install -e '.[dev]'
DATA_DIR=../data .venv/bin/uvicorn app.main:create_app --factory --reload --port 8080
.venv/bin/pytest && .venv/bin/ruff check . && .venv/bin/mypy app

# Frontend (Node 22) — dev server proxies /api to :8080
cd frontend && npm install && npm run dev
npm test && npm run check && npm run lint
```

Releases: push a tag `vX.Y.Z`; CI publishes a multi-arch image to `ghcr.io/kinsoi/yotube`.
````
